# 组件

选择组件可查看 H5 交互演示、原生源码、平台支持证据，以及用法和 API。原生标签页不运行 Vue 小程序，编译产物预览也不能代替真机验证。

能否安装到所选 profile，取决于组件及其全部依赖的 manifest 是否允许该 profile。六个新增 profile 均为 experimental，详见[支持边界](/guide/installation#安装-profile-与支持边界)。
