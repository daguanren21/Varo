# Loading 加载

`VLoading` 是 Base Kit 的低层加载指示器。

## Props

| Prop | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 尺寸 |
| `tone` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'danger'` | `'default'` | 色调 |
| `text` | `string` | `undefined` | 文案 |
