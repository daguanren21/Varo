## Props

| Prop        | 类型      | 默认值      | 描述                     |
| ----------- | --------- | ----------- | ------------------------ |
| `value`     | `number`  | `0`         | 当前值                   |
| `min`       | `number`  | `0`         | 最小值                   |
| `max`       | `number`  | `100`       | 最大值                   |
| `step`      | `number`  | `1`         | 步进                     |
| `ariaLabel` | `string`  | `undefined` | 滑块输入控件的无障碍名称 |
| `disabled`  | `boolean` | `false`     | 禁用                     |
