# Retail Starter 提案

::: warning 尚未开售
**¥399 仅是拟议的一次性试售价格，不是当前报价。** 不接受订单、付款或预订，也不承诺上线日期。

面向能自行接入后端的独立开发者、工作室和小团队，将零售前端流程整理成可编辑、可独立运行的工程，减少从零整合工作。它不是全托管商城。

## 拟交付内容

- 独立工程源码、依赖锁文件、版本说明和安装步骤。
- 商品浏览、购物车、地址、结算及模拟订单流程。
- 品牌与素材替换入口、本地模拟数据和 HTTP 接入示例。
- 对应版本的使用说明、验证记录和已知限制。

## 范围

目标为 **Wevu + weapp-vite + weapp-tailwindcss 原生微信小程序**，不含独立 H5 零售工程，不默认兼容 uni-app 或 Taro。

生产后端、鉴权、支付、退款和物流由使用方接入；默认订单仅在内存中模拟，不是实际交易。构建与浏览器演示不代表真机验证或审核保证。
