# Order Filter Block

`Order Filter` is a Base Kit filter block that uses `VSelect` for multi-select order statuses. It targets the `weapp-vite` registry and works as a basic filter bar for order lists.

## Registry

- Target: `weapp-vite`
- Dependencies: `components/select`
- File: `src/components/blocks/order-filter.vue`

## Boundary

This block stays lightweight with local status selection and basic layout. Remote dictionaries, grouped options, paged search, and API query mapping belong in secondary business wrappers.
