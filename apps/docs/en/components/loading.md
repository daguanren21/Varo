## Props

| Prop   | Type                                                           | Default     | Description   |
| ------ | -------------------------------------------------------------- | ----------- | ------------- |
| `size` | `'sm' \| 'md' \| 'lg'`                                         | `'md'`      | Size          |
| `tone` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'danger'` | `'default'` | Tone          |
| `text` | `string`                                                       | `undefined` | Optional text |
