# 国际化配置

Varo primitives 不内置固定文案。组件库只负责结构与交互，最终显示文本由业务侧决定。

## Vue I18n 示例

```ts
import { createApp } from 'vue'
import { createI18n } from 'vue-i18n'
import App from './App.vue'

const i18n = createI18n({
  legacy: false,
  locale: 'zh-CN',
  fallbackLocale: 'en-US',
  messages: {
    'zh-CN': { submit: '提交', cancel: '取消' },
    'en-US': { submit: 'Submit', cancel: 'Cancel' }
  }
})

createApp(App).use(i18n).mount('#app')
```

## 推荐约束

- 不要把业务文案直接写进 primitives
- wrappers 通过 props、slots 或业务 i18n 输出最终文案
- 小程序端也遵循同样策略，避免组件层与翻译层耦合
